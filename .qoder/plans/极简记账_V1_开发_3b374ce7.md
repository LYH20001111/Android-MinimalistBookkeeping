# 极简记账 App V1.0 开发方案

## 摘要

在 `d:\GitHub_Project\Development\Minimalist Bookkeeping` 现有工程（AGP 9.1.1 / Gradle 9.3.1 / compileSdk 36.1 / minSdk 24 / Java）上，按 markdown 基线实现完整 V1 MVP。

已确认的关键决策：
- 底部导航 **3 Tab**：记录 / 图表 / 我的（预算不单列 Tab，出现在图表页 + 我的→预算设置）
- 图表 **自绘 Canvas 自定义 View**，不引入第三方图表库
- 技术栈：Android + **Java** + **Room 2.8.4**（`annotationProcessor`）+ ViewModel/LiveData + Material 3
- 金额统一 `long`（单位：分），占比用整数千分比计算，**全程不出现 double/float 金额**
- V1 无网络权限、无登录、本地优先

工程现状必须处理的两个问题：
1. `MainActivity.java`、`ExampleUnitTest.java`、`ExampleInstrumentedTest.java` 三个文件已损坏为二进制乱码（文件头 `TSZ#`），需删除后重写。
2. `JAVA_HOME` 为空且 `java` 不在 PATH，所有 Gradle 命令前需设置 `$env:JAVA_HOME="D:\Program Files\Android\Android Studio\jbr"`。

## 阶段 1：数据层（`data` 包）

包路径根：`com.skyanchor.bookkeeping`

### `data/entity/`

| 类 | 表名 | 关键字段 |
|:---|:---|:---|
| `CategoryEntity` | `category` | `id`(PK,auto)、`name`、`icon`(emoji 字符串)、`type`(1支出/2收入)、`sortOrder`、`isDefault` |
| `TransactionEntity` | `transactions` | `id`(PK,auto)、`type`、`amount`(分)、`categoryId`(FK→category, `onDelete=CASCADE`, 建索引)、`date`(业务日期当天 00:00 的 epoch millis, 建索引)、`time`("HH:mm")、`note`(≤100,可空)、`createdAt`、`updatedAt` |
| `BudgetEntity` | `budget` | `id`(PK,auto)、`year`、`month`(1-12)、`amount`(分)、`createdAt`、`updatedAt`；`(year,month)` **唯一索引** |
| `UserSettingsEntity` | `user_settings` | `id`(PK 固定为 1，单例)、`theme`("light"/"system")、`firstLaunch`、`createdAt`、`updatedAt` |
| `TransactionItem` | — | JOIN 投影 POJO：交易字段 + `categoryName` + `categoryIcon`（单次查询，避免 `@Relation` 的 N+1） |

> 表名用 `transactions` 而非 `transaction`，规避 SQLite 关键字。字段完全对齐文档 12.1，不新增列。

### `data/database/`
- `TransactionDao`
  - `LiveData<List<TransactionItem>> observeBetween(long startDay, long endDay)`（LEFT JOIN category，`ORDER BY date DESC, time DESC, id DESC`）
  - `LiveData<List<TransactionItem>> observeAll()`
  - `TransactionItem getById(long id)`（同步，仅在执行器调用）
  - `long insert(...)` / `void update(...)` / `void deleteById(long id)` / `void deleteAll()`
  - `LiveData<Long> sumAmount(int type, long start, long end)`（`COALESCE(SUM(amount),0)`）
  - `int countByCategory(long categoryId)`（分类删除守卫）
  - `int countAll()`
- `CategoryDao`：`observeByType(int type)`、`observeAll()`、`getById`、`insertAll`（`OnConflictStrategy.IGNORE`）、`insert`、`update`、`deleteById`、`countByType(int)`、`swapSort` 用的按 sortOrder 查询、`deleteAll()`
- `BudgetDao`：`LiveData<BudgetEntity> observe(int year, int month)`、`BudgetEntity get(int year,int month)`、`upsert`、`delete(int year,int month)`、`deleteAll()`
- `UserSettingsDao`：`LiveData<UserSettingsEntity> observe()`、`get()`、`upsert()`
- `AppDatabase`：`@Database(version = 1, exportSchema = false)`，静态单例 `getInstance(Context)`；`RoomDatabase.Callback#onCreate` 中写入文档第 6 章的 **10 个支出默认分类 + 6 个收入默认分类** 和 `UserSettings` 单例（`theme="light"`、`firstLaunch=true`）

### `data/repository/BookkeepingRepository`
- 持有 `AppDatabase` + `ExecutorService io = Executors.newSingleThreadExecutor()`
- 读：直接转发 DAO 的 LiveData
- 写：全部在 `io` 执行器上跑，通过 `Callback`（自定义 `interface Callback<T>{ void onResult(T v); }`，主线程回调用 `Handler(Looper.getMainLooper())`）返回结果
- 提供 `warmUp()`（触发建库 + 默认分类写入，App 启动时在 IO 线程调用）
- 提供 `clearAllData()`：清 4 张表后重新写入默认分类与默认设置

### `BookkeepingApp`（Application）
- 单例暴露 `getRepository()`
- `onCreate` 中：`repository.warmUp()`；读取 theme 并调用 `AppCompatDelegate.setDefaultNightMode(...)`

## 阶段 3：主框架 + 记录页

### `MainActivity`
- `activity_main.xml`：`FragmentContainerView` + `BottomNavigationView`（`res/menu/bottom_nav_menu.xml`，3 项）
- Fragment 管理用 `FragmentManager` 的 **add / hide / show**（tag 分别为 `record`/`chart`/`mine`），保证切换不丢状态（文档 15 章要求）；`onSaveInstanceState` 保存当前选中 tag

### `ui/record/RecordFragment` + `viewmodel/RecordViewModel`
- 顶部「业务日期」按钮（默认今天）→ `MaterialDatePicker`；选中的业务日期存在 ViewModel 中，切 Tab 不丢
- 今日概览卡片：3 列 **今日支出 / 今日收入 / 结余**（结余 = 收入 − 支出，来自文档 11 章规则）
- 账单列表：`RecyclerView` + `adapter/TransactionListAdapter`（`ListAdapter` + `DiffUtil`），数据为「日期分组标题行 + 交易行」的扁平列表
  - 分组标题：`今天` / `昨天` / `9月2日` / `2025年12月3日`（相对所选业务日期），右侧显示当日支出合计
  - 交易行：emoji 圆形底 + 分类名 + 备注（辅助色，为空不显示）+ 时间 + 金额（支出用 `text_primary` 前缀 `-`，收入用 `success` 前缀 `+`）
  - 单击 → `TransactionEditActivity`（编辑模式）；长按 → 删除二次确认弹窗
  - 数据范围：`date <= 所选业务日期` 的全部账单，倒序（即文档 IA 的「历史账单」）
- 空状态：无账单时显示引导视图（图标 + 「还没有账单」+「记一笔」按钮），不显示空白列表
- `FloatingActionButton`（`ic_add`）→ 新增账单

### `ui/record/TransactionEditActivity`
- 新增/编辑复用同一 Activity，`Intent` extra `EXTRA_TRANSACTION_ID`（缺省为新增）
- 类型切换：`MaterialButtonToggleGroup`（支出/收入），切换后重载对应分类网格
- 金额：`TextInputEditText`（`numberDecimal`），上方 Display 字号实时预览 `¥35.80`
- 分类：`RecyclerView` + `GridLayoutManager(4)`，emoji + 名称，单选，默认选中该类型 `sortOrder` 最小的分类
- 日期按钮 → `MaterialDatePicker`（默认取记录页的业务日期）；时间按钮 → `MaterialTimePicker`（默认当前时间）
- 备注：`TextInputEditText`，`maxLength=100`
- 保存：主色按钮；校验金额 > 0 且已选分类，失败给 `TextInputLayout` 错误提示
- 编辑模式额外显示「删除」按钮（`danger`），点击弹二次确认
- 保存成功 → `finish()`；记录页与图表页通过 LiveData 自动刷新（满足「统计一致性」）

### `util/`
- `AmountUtil`：`format(long cents)`（纯整数分组格式化，输出 `¥1,280.00`）、`formatSigned`、`parseToCents(String)`（用 `BigDecimal.movePointRight(2).setScale(0, HALF_UP)`，精确无浮点误差）、`abbreviate(long)`（图表 Y 轴 `¥1.2k`）
- `DateUtil`：`startOfDay`、`startOfWeek`（**周一为本周第一天**）、`DateRange ofWeek/ofMonth/ofYear`（各含 `start`、`end`、`previous()`）、`dayHeaderLabel`、`periodLabel`
- `StatisticsCalculator`：`PeriodSummary summary(items)`、`List<TrendPoint> dailyTrend/monthlyTrend`、`List<CategoryStat> categoryBreakdown(items, type)`（降序 + 千分比整数占比）、`BudgetState budgetState(budgetAmount, expense)`
- `CategoryColors`：`colorOf(long categoryId)` → 稳定取 `chart_1..chart_10`（按 id 取模，保证同一分类跨周期颜色一致）

## 阶段 4：图表页

### `ui/chart/ChartFragment` + `viewmodel/ChartViewModel`
- 周期切换：`MaterialButtonToggleGroup`（周/月/年）
- 周期导航：`‹  2024年5月  ›`，`›` 在当前周期时禁用；周显示 `5月13日 - 5月19日`，年显示 `2024年`
- `ChartViewModel` 持有 `MutableLiveData<PeriodQuery>`（周期类型 + 锚点日期），经 `Transformations.switchMap` → `repository.observeBetween(range.start, range.end)`（范围覆盖**当前周期 + 上一相同周期**，用于环比）→ `Transformations.map` → `ChartUiState`
- 四层信息（严格对齐文档 7.1）：
  1. **核心数字**卡片：收入 / 支出 / 结余
  2. **环比**：支出较上一周期 `↑12.5%` / `↓8.5%` / `—`（上期为 0 时）；上升用 `danger`，下降用 `success`。计算 `(cur-prev)*1000/prev` 后格式化为一位小数，不用浮点
  3. **趋势**：`LineChartView`。周=7 个日点、月=当月天数日点、年=12 个月点
  4. **预算卡片**（仅月视图）：本月预算 / 已消费 / 剩余 / 使用率 + `LinearProgressIndicator`；状态色按文档 8.2（<80% `primary`、80%~100% `warning`、>100% `danger` 并显示超出金额）；未设置预算时显示「尚未设置本月预算」+「去设置」跳转 `BudgetSettingActivity`
  5. **分类占比**：`DonutChartView` + 排名列表（`adapter/CategoryStatAdapter`：色点、分类名、金额、占比、细进度条），按金额降序
- 空状态：本周期无账单时隐藏所有图表，显示引导卡片 +「记一笔」按钮（满足「不允许图表展示空白块」）

### `ui/widget/LineChartView`（自绘）
- `onDraw`：横向 4 条网格线（`divider` 色）+ Y 轴金额标签（`AmountUtil.abbreviate`）+ X 轴标签（周：一~日；月：1/5/10/15/20/25/末；年：1~12月）
- 折线 `primary` 色 2dp 描边 + 圆角连接；下方 `primary` 12%→0% 线性渐变填充；数据点 3dp 圆点
- 最高点标注数值气泡；触摸时显示竖直辅助线 + 对应点数值（`onTouchEvent` + `invalidate`）
- 全 0 数据时绘制基线 + 「暂无趋势数据」文案，不崩溃
- 支持 `setData(List<TrendPoint>)`，值变化时做简单的 `ValueAnimator` 绘制动画（250ms）

### `ui/widget/DonutChartView`（自绘）
- 环形图（`drawArc` + `Paint.Style.STROKE`，环宽 20dp），段间 2dp 间隙，颜色来自 `CategoryColors`
- 圆心显示总支出金额 + 「总支出」文案
- 支持 `setData(List<CategoryStat>)`；空数据时绘制 `divider` 色完整圆环

## 假设与说明

- 严格以 markdown 基线为准；原型图中的 5 Tab、首页仪表盘、账户/用户实体、分类预算表均**不在 V1 范围**（文档 3.1、4、12 章已明确排除）。
- 分类颜色为文档未定义的展示细节，采用 `id` 取模的稳定调色板实现，不改数据库 schema。
- 业务日期仅在会话内（ViewModel）保存，重启回到今天，符合「默认当前业务日期」。
- Room 版本首选 2.8.4，若与 AGP 9.1.1 冲突则回退 2.6.1，其余设计不变。
- 不使用 Navigation Component，用 `FragmentManager` add/hide/show 保证 Tab 切换状态不丢，减少依赖与版本风险。
