### 1.2 `TransactionDao.java` 新增查询

```java
// 日历摘要：指定日期范围内每天的收支合计
@Query("SELECT date AS day, "
     + "COALESCE(SUM(CASE WHEN type = 1 THEN amount ELSE 0 END), 0) AS expense, "
     + "COALESCE(SUM(CASE WHEN type = 2 THEN amount ELSE 0 END), 0) AS income, "
     + "COUNT(*) AS transactionCount "
     + "FROM transactions WHERE date BETWEEN :startDay AND :endDay "
     + "GROUP BY date ORDER BY date ASC")
LiveData<List<DailySummary>> observeDailySummaries(long startDay, long endDay);

// 周期选择器：每天账单笔数（Java 侧聚合为周/月/年）
@Query("SELECT date AS day, COUNT(*) AS transactionCount "
     + "FROM transactions GROUP BY date ORDER BY date ASC")
LiveData<List<DayCount>> observeDayCounts();
```

### 1.3 `BookkeepingRepository.java` 新增方法

```java
public LiveData<List<DailySummary>> observeDailySummaries(long startDay, long endDay)
public LiveData<List<DayCount>> observeDayCounts()
```

### 1.4 数据库外键修正（CASCADE → RESTRICT）

**`TransactionEntity.java`**：`onDelete = ForeignKey.CASCADE` → `onDelete = ForeignKey.RESTRICT`

**`AppDatabase.java`**：`version = 1` → `version = 2`，新增 `MIGRATION_1_2`：
```sql
PRAGMA foreign_keys=OFF;
CREATE TABLE transactions_new (
  id INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
  type INTEGER NOT NULL, amount INTEGER NOT NULL,
  category_id INTEGER NOT NULL, date INTEGER NOT NULL,
  time TEXT NOT NULL, note TEXT, created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL,
  FOREIGN KEY(category_id) REFERENCES category(id) ON DELETE RESTRICT
);
INSERT INTO transactions_new SELECT * FROM transactions;
DROP TABLE transactions;
ALTER TABLE transactions_new RENAME TO transactions;
CREATE INDEX index_transactions_category_id ON transactions(category_id);
CREATE INDEX index_transactions_date ON transactions(date);
PRAGMA foreign_keys=ON;
```
在 `Room.databaseBuilder` 中追加 `.addMigrations(MIGRATION_1_2)`。

```java
/** ISO 周序号（Calendar.WEEK_OF_YEAR），仅用于 UI 显示。 */
public static int weekOfYear(long millis) {
    Calendar cal = calendar(millis);
    cal.setFirstDayOfWeek(Calendar.MONDAY);
    cal.setMinimalDaysInFirstWeek(4);
    return cal.get(Calendar.WEEK_OF_YEAR);
}
```

## 阶段 4：周期选择器

### 4.1 `ChartViewModel.java` 扩展

新增字段与方法：
```java
private final LiveData<List<PeriodOption>> weekOptions;
private final LiveData<List<PeriodOption>> monthOptions;
private final LiveData<List<PeriodOption>> yearOptions;

// 构造函数中：
LiveData<List<DayCount>> dayCounts = repository.observeDayCounts();
weekOptions  = Transformations.map(dayCounts, c -> buildWeekOptions(c));
monthOptions = Transformations.map(dayCounts, c -> buildMonthOptions(c));
yearOptions  = Transformations.map(dayCounts, c -> buildYearOptions(c));

public LiveData<List<PeriodOption>> getPeriodOptions(PeriodType type)
public void selectAnchorDate(long anchorDate)   // 周期选择器回调
public void backToCurrentPeriod()               // anchorDate = today
```

`buildXxxOptions` 逻辑：
- 从 DayCount 列表取最小日期作为起点，today 作为终点
- 生成该范围内所有周/月/年的 PeriodOption
- 用 DayCount 填充每个周期的 transactionCount
- 无流水周期显示 `0笔`（周期选择器允许显示空周期）
- title/subtitle 由 `DateLabels` 生成（需要 Context，在 ViewModel 中通过 `getApplication()` 获取）

### 4.2 新增 `PeriodPickerDialog.java`（`ui/chart/`）

DialogFragment：
- 参数：`ARG_PERIOD_TYPE`、`ARG_CURRENT_ANCHOR`
- 通过 `ViewModelProvider(requireParentFragment()).get(ChartViewModel.class)` 获取 ViewModel
- 观察 `viewModel.getPeriodOptions(type)` 渲染列表
- RecyclerView + GridLayoutManager（周/月 2列，年 3列）
- 当前选中周期高亮（primary 边框）
- 点击周期 → `viewModel.selectAnchorDate(option.start)` → dismiss
- 回调接口 `OnPeriodSelectedListener` 由 ChartFragment 实现（可选，也可直接操作 ViewModel）

### 4.3 新增 `PeriodOptionAdapter.java`（`ui/chart/`）

ListAdapter + DiffUtil，每格显示：
- title（"Week 5" / "2026年8月" / "2026年"）
- subtitle（"08.30-09.05"）
- count（"6笔"）
- 选中状态：primary 边框 + primary_light 背景

### 4.4 新增布局文件
