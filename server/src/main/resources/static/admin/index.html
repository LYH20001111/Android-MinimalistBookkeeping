恢复

恢复会覆盖服务器当前全部数据，并影响所有设备。

  • 恢复期间所有设备的同步将暂时中断；
  • 恢复后所有设备必须重新登录（登录令牌不会恢复）；
  • 恢复后 App 会自动重置同步游标并重新收敛数据。
